## Selected Engineering Work

### NORRY GHOSTY // OSINT Intelligence
A specialized open-source intelligence platform engineered to aggregate, parse, and visualize public records and domain registries securely. The system manages extensive data querying for WHOIS lookups and historical DNS records, routing intelligence data through a secure Node.js intermediary layer to prevent payload tampering and manage rate limits dynamically.

### Titan Cargo
An enterprise-grade logistics platform managing cargo distribution and shipment tracking algorithms. The core database schema handles multi-layered relationships between waypoints, shipments, dispatchers, and drivers. Secured via rigorous JWT authentication and Role-Based Access Control (RBAC) to ensure immutability of cargo data.

### Press'dPretty
A fully integrated e-commerce storefront architecture. Built from scratch with deeply normalized PostgreSQL schemas to handle complex variations in custom product sizing and bespoke orders. The Express.js backend securely handles customer sessions, preparing the architecture for third-party payment gateway integration.

### Sneko
An ambitious real-time gameplay engine built entirely in JavaScript, integrating TensorFlow.js directly into the browser to run deep Q-learning inference locally. Maintains 60 FPS gameplay without server roundtrips, backed by a real-time telemetry dashboard that graphs epsilon decay and neural activations.
